 AI/ML Engineering Internship Tasks - DevelopersHub Corporation

This repository contains the completed tasks for the AI/ML Engineering Internship at DevelopersHub Corporation. All tasks are implemented using Python in Google Colab notebooks.

 Completed Tasks

Task 1: Exploring and Visualizing a Simple Dataset
- Objective:Load, inspect, and visualize the Iris dataset to understand feature relationships.
- Dataset: Iris Dataset (loaded via Seaborn).
- Key Results: Explored summary statistics and visualized distributions using Scatter, Histogram, and Box plots to analyze feature spreads and identify variations across species.

Task 2: Predict Future Stock Prices (Short-Term)
- Objective: Use historical stock data to predict the next day's closing price.
- Dataset: Apple (AAPL) stock market data fetched via the Yahoo Finance API (`yfinance`).
- Model Applied: Linear Regression.
- Key Results: Successfully trained the regression model on features like Open, High, Low, and Volume, and plotted actual vs. predicted closing prices to show model performance.

Task 6: House Price Prediction
- Objective: Predict house prices based on various property features.
- Dataset:California Housing Dataset.
- **Model Applied:** Gradient Boosting Regressor.
- **Key Results:** Evaluated performance using Mean Absolute Error (MAE) and Root Mean Squared Error (RMSE). Plotted a scatter plot comparing actual versus predicted real estate prices.
